## 1. نظرة عامة على النماذج البصرية (Prototype Scope)

تم بناء النموذج البصري التفاعلي باستخدام **React 18 و TypeScript الصارم و Vite** دون التأثير إطلاقاً على عمل الموقع الحالي (`server.js`). يجسد هذا النموذج الهيكل المعماري والجمالي الكامل للمنصة وفق نظام الرموز الدلالية (Tokens) ويدعم 5 سيناريوهات فحص رئيسية:

| النموذج | السيناريو | المكونات المعروضة |
|---|---|---|
| **Prototype A** | لوحة القيادة التنفيذية بالوضع الفاتح (Light Theme) | هيكل التطبيق الكامل، الشريط العلوي، القائمة الجانبية، بطاقات KPI، رسوم بيانية تفاعلية، وتدفق الأنشطة الأخيرة. |
| **Prototype B** | لوحة القيادة بالوضع الداكن (Dark Theme) | تباين رصين، ألوان مدروسة للرسوم البيانية، خلفيات فحمية غير متوهجة، وحماية راحة العين في بيئات العمل الطويلة. |
| **Prototype C** | صفحة تفصيلية لوحدة ذكاء الأعمال (Intelligence Detail) | شاشة الذكاء المالي والقرارات: خيارات تصفية متقدمة، جداول رصد الانحرافات، مؤشرات الثقة، وتفاصيل التدقيق. |
| **Prototype D** | تجربة الشاشات الضيقة والهواتف (Mobile Viewport) | استجابة القائمة الجانبية (Drawer mode)، إعادة ترتيب بطاقات KPI، وسلاسة تصفح الجداول على الأجهزة المحمولة. |
| **Prototype E** | التجربة العربية الأصيلة (Arabic RTL Experience) | محاذاة حقيقية من اليمين لليسار، خطوط عربية رصينة (Almarai / Readex Pro)، وتنسيق الأرقام والتواريخ منطقياً. |

## 2. كيفية تشغيل النموذج البصري محلياً (How to Run Locally)

النموذج البصري تم بناؤه وتجهيزه داخل مجلد `apps/platform`:

```bash
# الانتقال إلى مجلد التطبيق
cd apps/platform

# تثبيت الحزم (إذا لم تكن مثبتة مسبقاً)
pnpm install # أو npm install

# تشغيل خادم التطوير السريع Vite
pnpm dev # أو npm run dev
```

* سيعمل النموذج على العنوان: `http://localhost:5173` (أو المنفذ المتاح).
* العرض التجريبي الأصلي القديم يظل متاحاً ومستقلاً ويعمل عبر: `node server.js` على `http://localhost:3000`.

## 4. القيود الموثقة صراحة (Known Limitations & Honesty Statement)
* **بيانات تجريبية استرشادية:** جميع البيانات المعروضة في النموذج هي بيانات نموذجية استرشادية (Labeled Demonstration Data) ومصممة لاختبار نظام التصميم والتفاعل وتعدد اللغات.
* **لا يوجد اتصال بقاعدة بيانات حقيقية بعد:** قاعدة بيانات PostgreSQL والـ API الحقيقي يبدأ ربطهما في المرحلة 2 وفق خارطة الطريق المعتمدة.
